# Úvodní pokyn pro Claude Code

Tento text vlož do Claude Code jako první zprávu, až budou soubory `CLAUDE.md` a `docs/ZADANI.md` v repozitáři.

---

Ahoj, stavíme projekt KoronaBar Poker. Přečti si pozorně `CLAUDE.md` a celé `docs/ZADANI.md`.

Zatím nepiš žádný kód. Nejdřív mi připrav plán a ulož ho do `docs/PLAN.md`:
1. Porovnání pokerových enginů ze zadání a doporučení jednoho se zdůvodněním.
2. Architektura (server, klient, databáze, moduly a háčky, systém nastavení, oprávnění).
3. Datový model (hlavní tabulky a vztahy, hlavně účetní kniha, hry, handy, nastavení, role).
4. Rozpis všech fází na konkrétní kroky.
5. Seznam otevřených otázek a tvoje návrhy na vylepšení nebo věci, které v zadání chybí.

Pak mi plán česky a srozumitelně shrň a počkej na moje schválení.
